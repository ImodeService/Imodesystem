# Launcher (หน้า Login + หน้าเลือกโมดูล)

| ไฟล์ | หน้าที่ |
|---|---|
| `login.html` + `login.js` | หน้าเข้าสู่ระบบ (ชื่อผู้ใช้ + รหัสผ่าน, จำฉันไว้, แสดงรหัสผ่าน) |
| `index.html` + `launcher.js` | หน้าเลือกโมดูล ไอคอนแบบ Odoo โลโก้ I-MODE ตรงกลาง เมนูผู้ใช้และออกจากระบบ |
| `launcher.css` | หน้าตาทั้งสองหน้า (ใช้สีและฟอนต์จาก `shared/theme.css`) |

ของที่ใช้ร่วมอยู่ใน `shared/`: `config.js` (Supabase project เดียวกับระบบเดิม), `auth.js` (ล็อกอิน/เช็ก session/ออกจากระบบ), `theme.css`, `vendor/supabase.min.js`

## การทำงาน
- ล็อกอินด้วยบัญชี Supabase เดิม ชื่อผู้ใช้แปลงเป็น `<ชื่อ>@imode.local` เหมือนระบบเดิม
- รับเฉพาะพนักงาน: บัญชีลูกค้า บัญชีที่ปิดใช้งาน หรือไม่มีแถวใน `profiles` จะถูกปฏิเสธ
- ไม่ติ๊ก "จำฉันไว้" = ปิดเบราว์เซอร์แล้วต้องล็อกอินใหม่
- หน้าเลือกโมดูลเปิดไม่ได้ถ้ายังไม่ล็อกอิน (เด้งกลับหน้า Login)
- โมดูลที่ยังไม่มีขึ้นป้าย "เร็วๆ นี้" รายการโมดูลอยู่ใน `MODULES` ใน `launcher.js`

## ยังไม่ได้ทำ
- ซ่อนโมดูลตามสิทธิ์รายคน (รอโมดูลบัญชีและสิทธิ์ + ตารางสิทธิ์ใน Supabase)
- ตัวเลขแจ้งเตือนบนไอคอน (รอข้อมูลจริงจากแต่ละโมดูล)
- Service ยังเป็นระบบเดิมที่มีล็อกอินของตัวเอง กดเข้าไปแล้วต้องล็อกอินอีกรอบ จนกว่าจะปรับให้ใช้ `shared/auth.js`
- ลืมรหัสผ่านแบบส่งอีเมล (บัญชีใช้ @imode.local ซึ่งรับอีเมลไม่ได้)
