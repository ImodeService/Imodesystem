ศูนย์การแจ้งเตือน

นัดหมาย เคสด่วน งานรออะไหล่ และการส่งงาน

1. อ้างอิงเคสและลูกค้า

เลือกเคสเพื่อดึงข้อมูลลูกค้าและเครื่องอัตโนมัติ

2. เงื่อนไขบริการ

ประเภทบริการ ระยะทาง ความเร่งด่วน และ Warranty

เลือก customer เพื่อคำนวณระยะทางอัตโนมัติ
แสดงเฉพาะเมื่อเลือก “ซื้อ / ต่อประกันเครื่อง”

3. เครื่องจักร

เครื่องแรกคิดเต็มราคา เครื่องถัดไปใช้อัตรา Additional Machine

เครื่องต้องระบุ Size S/L ใน Machine Master เพื่อคำนวณราคาได้ถูกต้อง

4. ค่าแรงเพิ่มเติม / Diagnosis

5. Spare Parts

คำนวณราคาขายจากต้นทุนและประเภทอะไหล่

Diagnosis Only: ล็อกรายการอะไหล่ และไม่คิดค่าอะไหล่ในใบเสนอราคา

6. ค่าใช้จ่ายอื่น / ส่วนลด

7. หมายเหตุเพิ่มเติม

ข้อความนี้จะแสดงในช่องหมายเหตุของใบเสนอราคาและแก้ไขได้

8. ลายเซ็นฝั่งบริษัท

ลงลายเซ็นผู้อนุมัติและผู้จัดทำได้เลย ระบบจะบันทึกพร้อมใบเสนอราคา
