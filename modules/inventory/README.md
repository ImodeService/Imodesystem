# inventory

ระบบบริหารคลังสินค้า (สต๊อก) — `index.html` คือไฟล์ IMODE_Inventory v1.1 จากเจ้าของ นำมาวางทั้งไฟล์ ยังไม่ได้แก้

สถานะตอนนี้ (2026-10-14):
- เป็นหน้าเดียวจบ เก็บข้อมูลใน localStorage ของเบราว์เซอร์ (`imode_inventory_v2`) ยังไม่ต่อ Supabase
- ผู้ใช้/บทบาทเป็นแบบจำลอง สลับได้ในหน้าจอ ยังไม่ใช้ login กลางของแพลตฟอร์ม
- เปิดได้จาก launcher (ไทล์ Inventory)

ขั้นต่อไป: ต่อ login กลาง (shared/auth.js), ย้ายข้อมูลขึ้น Supabase พร้อม RLS, แยก CSS/JS ออกจากไฟล์เดียว
