# inventory

ระบบบริหารคลังสินค้า (สต๊อก) — `index.html` คือไฟล์ IMODE_Inventory v1.1 จากเจ้าของ นำมาวางทั้งไฟล์ ยังไม่ได้แก้

สถานะตอนนี้ (2026-10-14):
- เป็นหน้าเดียวจบ เก็บข้อมูลใน localStorage ของเบราว์เซอร์ (`imode_inventory_v2`) ยังไม่ต่อ Supabase
- ผู้ใช้/บทบาทเป็นแบบจำลอง สลับได้ในหน้าจอ ยังไม่ใช้ login กลางของแพลตฟอร์ม
- เปิดได้จาก launcher (ไทล์ Inventory)

ขั้นต่อไป: ต่อ login กลาง (shared/auth.js), ย้ายข้อมูลขึ้น Supabase พร้อม RLS, แยก CSS/JS ออกจากไฟล์เดียว

## เครื่อง Demo / ยืม-คืน (เพิ่ม 2026-10-16)
เมนู "เครื่อง Demo / ยืม-คืน" ในกลุ่มงานคลังสินค้า: บันทึกใครยืมเครื่องไหน เช็คลิสต์อุปกรณ์ (แก้ได้ทั้งแบบมาตรฐานและเฉพาะใบ) รูปก่อนให้ยืม/หลังรับคืน จำนวนวันยืมและกำหนดคืน แจ้งเตือนเลยกำหนด พิมพ์ใบยืม A4 ให้เซ็น แล้วติ๊ก/แนบรูปใบเซ็นกลับ
- ข้อมูลอยู่ใน `db.loans` / `db.loanTemplate` ของที่เก็บเดิม (`imode_inventory_v2`) จึงถูกสำรอง/กู้คืนไปด้วย
- ยังไม่ตัด/เพิ่มยอดสต๊อกของเครื่องที่ให้ยืม และข้อความเงื่อนไขในใบยืม (`LOAN_TERMS`) เป็นตัวอย่าง รอข้อมูลจริงจากทีม
- ปุ่ม "โหลดตัวอย่างการยืม" สร้างข้อมูลปลอม 4 รายการ (ลบได้ทีละใบ)

### เพิ่ม 2026-10-20
- ปุ่ม "กลับหน้าหลักสต๊อก" (และลิงก์ "หน้าหลัก" ใน breadcrumb) ทุกหน้าย่อยของโมดุล กลับไปหน้าภาพรวมคลังสินค้า
- เช็คลิสต์อุปกรณ์เฉพาะเครื่อง: ปุ่ม "แก้เช็คลิสต์อุปกรณ์" เลือกได้ว่าแก้แบบมาตรฐาน หรือของเครื่องในสต๊อก/เครื่องอื่นที่พิมพ์ชื่อเอง (เก็บใน `db.loanTemplates` คีย์ `p:<id สินค้า>` หรือ `n:<ชื่อเครื่อง>`) ตอนบันทึกการยืมเลือก/พิมพ์ชื่อเครื่อง รายการจะขึ้นให้เอง และติ๊ก "จำรายการนี้เป็นเช็คลิสต์ของเครื่องนี้" ได้
- ช่อง "ผู้นำเครื่องออก / ผู้ให้ยืม" ระบุพนักงานที่นำเครื่องออก
